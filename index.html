// Lo que he construido

Proyectos

Proyectos reales con datos públicos. Cada uno funciona hoy y se puede abrir.

  1. 01
    HTML / JavaScript / API pública / GitHub Actions

    Canarias Gas Tracker

    Las gasolineras más baratas de las islas, con filtro por isla y por combustible. Se alimenta de la API de precios del Ministerio y se actualiza sola cada día.

    Abrir la web Código
  2. 02
    Python / FBref / Power BI

    Moleiro frente al resto del Mundial

    ¿Cuánto produce Alberto Moleiro comparado con otros jugadores de las cinco grandes ligas? Un pipeline en Python que baja los datos de FBref y un dashboard en Power BI para leerlos.

    Código y dashboard
  3. 03
    Python / Leaflet / JavaScript / Pipeline de datos

    El mapa de Historia para Gandules

    Un mapa con 121 historias de @historiaparagandules, la cuenta de Luis Cabrera: cada vídeo anclado al lugar del que habla, con filtros, buscador y un juego para adivinar dónde ocurrió. Los datos salen de un pipeline en Python y la web solo lee un JSON.

    Abrir el mapa Código
  4. 04
    HTML / JavaScript / Google Sheets

    La Quiniela entre amigos

    Un panel para una quiniela de tres amigos: los resultados se rellenan en una hoja de Google publicada como CSV y la página calcula aciertos, media por jornada, mejor jornada y evolución acumulada.

    Abrir el panel Código
  5. 05
    Python / Pillow / matplotlib / ffmpeg

    La fábrica de contenido

    Los carruseles, reels y stories de @hbtdata salen de un conjunto de scripts con la identidad de la marca, gráficos propios y las reglas de siempre: barras desde cero, medianas, fecha y fuente.

    Verlo en Instagram

// Sobre mí

Henry Barrios Thornhill

Henry Barrios Thornhill (hbtdata) es analista de datos de Gran Canaria que programa con IA y autor de Abre tu sobre (abretusobre.es).

Soy de Las Palmas de Gran Canaria. Estudié ADE y un máster en Big Data, y trabajo con datos desde hace unos años: análisis, automatización de informes y dashboards.

Hoy lo hago en una agencia de comunicación de Gran Canaria y, en mi tiempo libre, construyo lo que ves arriba. Me gusta que un dato se entienda a la primera y que lo que hago se pueda abrir, tocar y comprobar.

Y fuera de la pantalla, varias veces al año me voy de voluntario con la Fundación Foresta a plantar especies autóctonas por Canarias.
