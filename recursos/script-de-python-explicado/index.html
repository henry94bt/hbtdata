Un script de Python que puedas mantener tú

Para pedir un script pequeño que haga algo repetitivo, con comentarios, instrucciones para ejecutarlo y una prueba.

Actualizado el 25 de noviembre de 2026

Para qué sirve

  • Renombrar archivos, juntar varios Excel, descargar datos públicos cada día.
  • Tener código que entiendes y puedes tocar, no una caja negra.
  • Empezar a programar con IA con buenas costumbres desde el principio.

El prompt

>_ prompt
Necesito un script de Python que haga esto: [qué tiene que hacer, con un ejemplo de entrada y de salida].

Condiciones:
- Python 3, con la menor cantidad posible de librerías externas. Si usas alguna, dime cómo instalarla.
- Comentarios en español explicando cada bloque.
- Los datos que pueden cambiar (rutas, fechas, nombres) arriba del todo, en variables.
- Que no borre ni sobrescriba nada sin avisar.
- Mensajes claros si algo falla.

Después:
1. Explícame cómo ejecutarlo paso a paso en [Windows / Mac].
2. Dame una forma de probarlo con datos de ejemplo antes de usarlo con los de verdad.
3. Dime qué partes tendría que cambiar si [un cambio probable, por ejemplo: el archivo llega con otra columna].

Un ejemplo de lo que sale

Respuesta de ejemplo
# ----- Configuración: cambia esto -----
CARPETA_ENTRADA = "informes_mensuales"
ARCHIVO_SALIDA = "todo_junto.xlsx"

# ----- Juntar todos los Excel de la carpeta -----
import pandas as pd
from pathlib import Path

archivos = sorted(Path(CARPETA_ENTRADA).glob("*.xlsx"))
if not archivos:
    raise SystemExit(f"No hay archivos .xlsx en {CARPETA_ENTRADA}")

Para probarlo: crea una carpeta con dos Excel pequeños inventados y ejecútalo ahí primero.

Consejos

  • Prueba siempre con una copia de tus archivos, nunca con los originales.
  • Si algo falla, pega el mensaje de error completo en el mismo chat: es lo que más ayuda a Claude.
